# PriorityBadge

Ticket priority, as decided by policy (never by the model). Text `priority-*` on `priority-*-soft`, always with the word.

Props: `priority` `emergency | high | normal | low`.

- **Emergency** is the only one in caps, with a solid border and the filled alert icon. Pair with the ticket's `border-edge` top edge — no other emphasis.
- High carries the outline alert icon; normal and low are text only.
- Screen readers hear "Priority: Emergency".
