# Icon

Inline SVG icons on a 24px grid, 1.75 stroke, round caps, `currentColor`, always `aria-hidden` (the adjacent word carries meaning). Names: alert, alertFill, shield, person, check, x, clock, tool, cpu, chevron, send, home.

`alertFill` = error / emergency; `shield` = rejected (guardrail held); `person` = human review.
