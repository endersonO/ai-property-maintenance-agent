# JsonBlock

Readable, syntax-tinted JSON (2-space indent) in `mono` on `subtle`. Keys `priority-normal`, strings `status-ok`, numbers `priority-high`, booleans/null `review` — each ≥ 4.5:1 on `subtle`. Scrolls horizontally, focusable for keyboard scrolling.

Props: `value` (object or pre-formatted string), `label`.
